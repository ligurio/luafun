Lua Functional Library
======================

:Release: 0.1
:Updated: Aug 10, 2024

**Lua Fun** is a high-performance functional programming library designed for
`LuaJIT <http://luajit.org/luajit.html>`_ and built around the tracing
just-in-time compiler.
